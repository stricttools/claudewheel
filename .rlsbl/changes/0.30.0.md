## 0.30.0

Quieter Claude Code sessions: launches disable the client self-updater and feature-flag evaluation, Remote Control auto-connect and spinner tips are off in every managed profile, the post-update summary is suppressed, and the launcher no longer offers plan mode.

<details>
<summary>Context</summary>

Claude Code 2.1.263 shows several startup notices that a claudewheel user
never wants: an auto-updater that installs over claudewheel's managed
versions, a server-delivered model-upsell tip, Remote Control connection
status, and a post-update changelog summary after every version switch.
Each was traced to its actual switch in the client. The updater and the
feature-flag system are only reachable through environment variables, so
the launch injects them; Remote Control auto-connect and spinner tips are
settings.json keys, so they joined the canonical model that the exact
reconcile enforces; the post-update summary has no switch at all and is
prevented by marking the launched version as already seen before exec.
Plan mode cannot be removed from the client's own Shift+Tab cycle, so the
launcher stops offering it instead, and a stale saved plan selection is
reset to default so it can never fall through to a bypass launch.

</details>

### Breaking

- **`plan` is no longer offered in the permissions segment.** The launcher offers `bypass` and `default`; an existing options.json is migrated. `plan` and `auto` remain accepted when pinned or passed with `--set`.

### Features

- **Quieter launches.** Every claudewheel launch now sets `DISABLE_AUTOUPDATER=1` and `DISABLE_GROWTHBOOK=1`, so Claude Code no longer self-updates over claudewheel's managed versions and no longer shows the server-delivered model-upsell tip (Remote Control is disabled as a side effect).
- **Remote Control and spinner tips off by default.** `remoteControlAtStartup` and `spinnerTipsEnabled` are now canonical settings keys: new profiles get both set to false, `patch-profiles`/`reconcile-permissions` make them exact in every managed profile, and `health` reports drift.
- **No more post-update summary.** Before launching, claudewheel marks the launched Claude Code version as seen in the profile's `.claude.json`, so the 'Updated to latest. Got N features...' banner no longer appears after a version switch.

### Fixes

- **A stale `plan` launch selection now resets to `default`.** Previously it restored unselected and the launch fell through to the default bypass flags.
